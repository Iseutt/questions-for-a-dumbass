# Host Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Host mode toggle: each question shows alone until the host clicks Start, which reveals the answers and starts a 30 s timer.

**Architecture:** One flag `store.host` (localStorage). `renderQ` in `js/app.js` hides the options/answer area behind a Start button when the flag is on; timer start moves into the reveal step. Toggle lives on the course page.

**Tech Stack:** Vanilla JS, static HTML/CSS, no build, no test framework (verification = manual in browser).

**Spec:** `docs/superpowers/specs/2026-11-17-host-mode-design.md`

## Global Constraints

- Host mode off by default; when off, behaviour identical to today.
- Host timer: 30 s for every MCQ in every mode (Quick Fire, Ladder, Training, My mistakes).
- Open questions in host mode: Start reveals textarea, no timer.
- Space / Enter triggers Start.

## Review Focus

- Pressing A–D / 1–4 before Start must not answer the question.
- Timer must not run (and "Time's up" must not fire) before Start.
- Quit before Start must not leave a timer running.
- Toggle state survives page reload and appears on every course page.
- Quick Fire speed bonus still computed from time left after Start.
